1. Access the UI
{{- if .Values.ingress.enabled }}
   http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "kubemind.fullname" . }} 8080:{{ .Values.service.port }}

2. Log in
   Username: {{ .Values.auth.adminUsername }}
   Password: the value you set in auth.adminPassword
   (or: kubectl -n {{ .Release.Namespace }} get secret {{ include "kubemind.secretName" . }} -o jsonpath='{.data.admin-password}' | base64 -d)

{{- if .Values.ollama.enabled }}

3. AI readiness
   The bundled Ollama pulls its models on first start
   ({{ .Values.ollama.chatModel }} is ~4.7GB) — AI features return errors until
   that finishes. Watch progress with:
     kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "kubemind.fullname" . }}-ollama -f
{{- else }}

3. AI backend
   Using external Ollama at {{ .Values.ollama.external.baseUrl }} — make sure
   models "{{ .Values.ollama.chatModel }}" and "{{ .Values.ollama.embeddingModel }}"
   are pulled there.
{{- end }}
{{- if not .Values.postgresql.enabled }}

4. Database
   Using your external PostgreSQL. Flyway migrates the schema on first boot,
   but the `vector` and `uuid-ossp` extensions must already exist (see the
   comment in migration V6__pgvector.sql).
{{- end }}

SECURITY REMINDERS
{{- if .Values.rbac.clusterAdmin }}
  * FULL PRIVILEGE (rbac.clusterAdmin=true). The backend ServiceAccount is bound
    to cluster-admin, so anyone who can log in to KubeMind as ADMIN effectively
    holds cluster-admin on this cluster. Set rbac.clusterAdmin=false for
    restricted mode if that is more power than you want to hand out.
{{- else }}
  * RESTRICTED MODE (rbac.clusterAdmin=false). No cluster-admin binding. The
    Cluster Terminal, Node Shell and RBAC-object writes are switched off in the
    app, so nothing offers what this role would be refused. Still granted, and
    worth a conscious decision: reading Secrets cluster-wide, and exec into pods.
{{- end }}
  * Never expose this deployment to the public internet. VPN or IP-allowlisted
    ingress + TLS only.
